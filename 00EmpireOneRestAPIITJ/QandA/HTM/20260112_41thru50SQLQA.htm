41) What is a SQL Server login versus a database user?
A SQL Server login provides access to the SQL Server instance, allowing authentication at the server level. A database user, on the other hand, is mapped to a login and provides access to a specific database. While a login allows a connection to the server, permissions inside a database are controlled through the associated database user.

42) What is the difference between CHAR and NCHAR, and VARCHAR and NVARCHAR?
CHAR and VARCHAR store non-Unicode data, while NCHAR and NVARCHAR store Unicode data. Unicode data can store multilingual characters and takes twice the storage per character compared to non-Unicode. CHAR and NCHAR are fixed-length, while VARCHAR and NVARCHAR are variable-length, making them more space-efficient for variable-length data.

43) What is a SQL Server deadlock and how can it be prevented?
A deadlock occurs when two or more transactions block each other, each waiting for a resource the other holds. SQL Server detects deadlocks automatically and terminates one transaction as a deadlock victim. Deadlocks can be prevented by keeping transactions short, accessing tables in the same order, using proper indexing, and avoiding long-running locks.

44) What is SQL Server transaction log and why is it important?
The transaction log records all changes made to the database, ensuring durability and consistency. It allows SQL Server to roll back incomplete transactions and recover the database in case of failure. Proper management of transaction logs is critical to prevent them from growing too large and to maintain database performance.

45) What is a SQL Server constraint?
A constraint is a rule applied to table columns to enforce data integrity. Common constraints include PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK, and DEFAULT. Constraints ensure that data entered into the table meets the business and relational rules defined for the database.

46) What is the difference between DELETE and TRUNCATE in SQL Server?
DELETE removes specific rows based on a condition and can be rolled back if within a transaction. It also fires triggers. TRUNCATE removes all rows from a table quickly, resets identity columns, and cannot be rolled back unless in a transaction. TRUNCATE does not fire triggers.

47) What is SQL Server indexing and what types are available?
Indexing improves query performance by allowing faster retrieval of data. Types of indexes include clustered, non-clustered, unique, filtered, columnstore, and full-text indexes. Choosing the right index type depends on query patterns and table structure.

48) What is the difference between INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL OUTER JOIN?
INNER JOIN returns only matching rows from both tables. LEFT JOIN returns all rows from the left table and matching rows from the right table, filling with NULLs if no match exists. RIGHT JOIN returns all rows from the right table and matching rows from the left. FULL OUTER JOIN returns all rows from both tables, with NULLs where matches do not exist.

49) What is a SQL Server trigger?
A trigger is a special type of stored procedure that automatically executes in response to INSERT, UPDATE, or DELETE operations on a table. Triggers are commonly used for auditing, enforcing business rules, and maintaining data integrity across related tables.

50) What is SQL Server replication and what types are available?
Replication copies and distributes data from one database to another to maintain consistency. It is commonly used for reporting, load balancing, and disaster recovery. Types include snapshot replication, transactional replication, and merge replication, each suited for different scenarios of data synchronization.
