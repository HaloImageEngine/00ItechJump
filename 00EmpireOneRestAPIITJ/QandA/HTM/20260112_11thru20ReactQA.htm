11) What is the difference between useEffect and useLayoutEffect in React?
Both useEffect and useLayoutEffect allow you to perform side effects in functional components, but they differ in timing. useEffect runs asynchronously after the DOM has been painted, making it suitable for tasks like fetching data. useLayoutEffect runs synchronously after the DOM updates but before the browser paints, making it useful for measuring or manipulating the layout to avoid flicker.

12) What is a key in React and why is it important?
A key is a unique identifier assigned to elements in a list to help React identify which items have changed, been added, or removed. Using keys improves performance by minimizing DOM manipulations and ensuring that components maintain their state correctly during re-renders. Without keys, React may re-render unnecessarily or mix up component states.

13) What is the difference between React.PureComponent and React.Component?
React.Component re-renders whenever its parent re-renders, regardless of whether props or state have changed. React.PureComponent implements a shallow comparison of props and state, preventing re-renders when nothing has changed. PureComponent helps improve performance but should be used only when shallow comparison is sufficient.

14) What is lazy loading in React?
Lazy loading is a technique to defer the loading of components until they are needed. In React, it is implemented using React.lazy() and Suspense. This reduces the initial bundle size and improves application performance by only loading code when a component is rendered.

15) What is the difference between React.Fragment and a <div>?
React.Fragment allows you to group multiple elements without adding extra nodes to the DOM, unlike a <div> which creates a new DOM element. Using fragments helps maintain cleaner HTML and avoids unnecessary wrappers, which is especially useful in lists and nested components.

16) What is reconciliation in React?
Reconciliation is the process by which React updates the DOM efficiently. When a component’s state or props change, React compares the new virtual DOM with the previous version (diffing) and calculates the minimum set of changes required to update the real DOM. This ensures optimal performance and minimal re-rendering.

17) What is the difference between React.StrictMode and normal rendering?
React.StrictMode is a tool used during development to highlight potential problems in an application. It runs certain lifecycle methods and hooks twice to detect side effects and warns about deprecated APIs. It does not affect production rendering but helps developers write more robust code.

18) What is a Higher-Order Component (HOC) in React?
A Higher-Order Component is a function that takes a component and returns a new component with added functionality. HOCs are used for cross-cutting concerns like authentication, logging, or theme injection without modifying the original component, promoting code reuse and separation of concerns.

19) What is the difference between server-side rendering (SSR) and client-side rendering (CSR) in React?
Client-side rendering loads a minimal HTML page and renders content in the browser using JavaScript, which can delay the time to first meaningful paint. Server-side rendering generates HTML on the server and sends it to the browser, improving performance and SEO. Frameworks like Next.js provide SSR support for React.

20) What is the difference between useCallback and useMemo?
useCallback memoizes a function, returning the same function instance between renders unless dependencies change. useMemo memoizes the result of a computation, recomputing it only when dependencies change. Both hooks help optimize performance by preventing unnecessary re-renders and recalculations.
