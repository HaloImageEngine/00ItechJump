21) What is the difference between List<T> and Array in C#?
An Array has a fixed size once it is created, while a List<T> is dynamic and can grow or shrink as needed. List<T> provides many helpful methods such as Add, Remove, and Find, making it easier to work with collections. Arrays are slightly faster and more memory efficient, but lists are more flexible and commonly used in business applications.

22) What is the purpose of the sealed keyword?
The sealed keyword prevents a class from being inherited. This is useful when you want to stop further extension of a class for security, performance, or design reasons. It can also be used on methods to prevent overriding in derived classes.

23) What is a partial class?
A partial class allows a class definition to be split across multiple files. This is commonly used in large projects and in auto-generated code, such as Windows Forms or Entity Framework models, where part of the class is generated by tools and part is written by the developer.

24) What is method overloading?
Method overloading allows multiple methods to have the same name but different parameter lists. The compiler determines which method to call based on the number, type, and order of parameters. This improves readability and allows related functionality to be grouped under a single method name.

25) What is method overriding?
Method overriding allows a derived class to provide its own implementation of a method that is defined in a base class. The base method must be marked as virtual, abstract, or override. This enables polymorphism, where the same method call behaves differently depending on the object type.

26) What is the difference between ref and out parameters?
Both ref and out pass parameters by reference, allowing the method to modify the original value. The difference is that ref requires the variable to be initialized before it is passed, while out does not. out parameters are often used when a method needs to return multiple values.

27) What is the purpose of the yield keyword?
The yield keyword is used to create an iterator. It allows a method to return values one at a time instead of all at once, which improves memory usage and performance when working with large collections. Each time the iterator is accessed, execution resumes from where it left off.

28) What is a record in C#?
A record is a reference type designed for immutable data models. It provides built-in value-based equality, meaning two records with the same data are considered equal. Records are commonly used in modern C# applications for DTOs and data transfer between layers.

29) What is the difference between First() and FirstOrDefault() in LINQ?
First() returns the first element of a sequence but throws an exception if the sequence is empty. FirstOrDefault() returns the first element or a default value, such as null for reference types, if the sequence is empty. FirstOrDefault() is safer when you are not sure whether data exists.

30) What is a deadlock?
A deadlock occurs when two or more threads are waiting for each other to release resources, causing all of them to stop executing. This commonly happens when locks are acquired in different orders. Avoiding deadlocks requires careful locking strategies, such as always acquiring locks in the same order.
