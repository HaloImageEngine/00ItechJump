In React, functional components are the modern and preferred way to build UI components because they are simpler, more readable, and easier to test than class-based components. A functional component is a plain JavaScript or TypeScript function that receives props as input and returns JSX describing what should appear on the screen. With the introduction of React Hooks such as useState, useEffect, and useContext, functional components can manage state, handle side effects, and share logic without needing classes or lifecycle methods. They promote better separation of concerns, reduce boilerplate code, and encourage composition by breaking complex UIs into smaller, reusable functions. Because functional components are lightweight and work seamlessly with modern React features like concurrent rendering and server components, they are now the standard approach for building scalable and maintainable React applications.

useState is a React Hook used to add and manage local state inside functional components. It allows a component to store values that can change over time, such as form inputs, counters, or UI toggles, and automatically triggers a re-render when the state updates. The hook returns the current state value and a setter function, encouraging immutable updates and predictable UI behavior. By keeping state logic close to where it is used, useState makes components easier to understand and maintain.

useEffect is a Hook that handles side effects in functional components, such as data fetching, subscriptions, timers, or manual DOM interactions. It runs after the component renders and can be configured to run on every render, only once, or when specific dependencies change. The cleanup function returned by useEffect allows developers to properly release resources like event listeners or intervals, preventing memory leaks. This hook replaces many class lifecycle methods and provides a unified way to manage component side effects.

useMemo is a performance optimization Hook that memoizes the result of an expensive calculation so it is only recomputed when its dependencies change. It helps avoid unnecessary recalculations during re-renders, especially when dealing with complex computations or derived data. While it does not prevent re-renders by itself, useMemo ensures that computationally heavy logic runs only when needed, improving performance in data-intensive or frequently updating components.

useCallback is a Hook used to memoize function references, ensuring the same function instance is reused between renders unless its dependencies change. This is particularly useful when passing callbacks to child components that rely on reference equality (such as those wrapped in React.memo) to avoid unnecessary re-renders. By stabilizing function references, useCallback helps optimize component performance and maintain predictable rendering behavior in complex component trees.
