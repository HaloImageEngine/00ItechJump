11) What is the difference between WHERE and HAVING?
The WHERE clause is used to filter rows before grouping occurs, while the HAVING clause is used to filter grouped results after a GROUP BY operation. WHERE works on individual rows, whereas HAVING works on aggregated data such as counts and sums.

12) What is the difference between INNER JOIN and LEFT JOIN?
An INNER JOIN returns only the rows that have matching values in both tables. A LEFT JOIN returns all rows from the left table and the matching rows from the right table, and if there is no match, it returns NULLs for the right table’s columns. LEFT JOIN is commonly used when you want all records from one table regardless of whether a match exists.

13) What is a composite key?
A composite key is a primary key that consists of two or more columns used together to uniquely identify a row. It is often used in junction tables, such as those that represent many-to-many relationships, where a single column is not sufficient to guarantee uniqueness.

14) What is an execution plan?
An execution plan is a detailed description of how SQL Server will execute a query. It shows which indexes are used, how tables are joined, and the estimated cost of each step. Execution plans are essential for query tuning and performance optimization.

15) What is a CTE (Common Table Expression)?
A CTE is a temporary result set defined using the WITH keyword that can be referenced within a SELECT, INSERT, UPDATE, or DELETE statement. It improves readability and is often used for recursive queries and complex data transformations.

16) What is the difference between ISNULL and COALESCE?
ISNULL replaces a NULL value with a specified replacement value and is specific to SQL Server. COALESCE returns the first non-NULL value from a list of expressions and is part of the SQL standard. COALESCE is more flexible when checking multiple columns.

17) What is a trigger?
A trigger is a special type of stored procedure that automatically executes when an INSERT, UPDATE, or DELETE occurs on a table. Triggers are commonly used for auditing, enforcing business rules, and maintaining data integrity.

18) What is a covering index?
A covering index is an index that contains all the columns needed to satisfy a query, either in the key or as included columns. This allows SQL Server to retrieve data directly from the index without accessing the table, which greatly improves query performance.

19) What is the difference between ROW_NUMBER() and RANK()?
ROW_NUMBER() assigns a unique sequential number to each row, even if values are the same. RANK() assigns the same rank to rows with equal values but leaves gaps in the ranking. These functions are commonly used for pagination and reporting.

20) What is database normalization vs denormalization?
Normalization organizes data into separate tables to reduce redundancy and improve integrity. Denormalization combines data into fewer tables to improve read performance. In SQL Server, normalized designs are common for transactional systems, while denormalized designs are often used in reporting and data warehouses.
