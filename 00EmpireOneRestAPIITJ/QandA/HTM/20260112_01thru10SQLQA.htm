1) What is SQL Server and what is it used for?
SQL Server is Microsoft’s relational database management system used to store, manage, and retrieve data efficiently. It supports structured data, transactions, security, backup and recovery, and high availability. SQL Server is widely used in enterprise applications, web applications, and data warehousing solutions because of its reliability, performance, and tight integration with the Microsoft .NET ecosystem.

2) What is the difference between a clustered and a non-clustered index?
A clustered index defines the physical order of data in a table, meaning the table itself is stored in the order of the clustered index. A table can have only one clustered index. A non-clustered index is a separate structure that contains pointers to the actual data rows, and a table can have multiple non-clustered indexes. Clustered indexes are best for range queries, while non-clustered indexes are best for fast lookups.

3) What is a primary key and a foreign key?
A primary key uniquely identifies each row in a table and cannot contain duplicate or null values. A foreign key is a column that references the primary key of another table, creating a relationship between the two. Foreign keys enforce referential integrity by ensuring that related data remains consistent across tables.

4) What is normalization in SQL Server?
Normalization is the process of organizing data into tables to reduce redundancy and improve data integrity. It involves breaking large tables into smaller related tables and defining relationships between them. Common normal forms such as 1NF, 2NF, and 3NF help ensure that data is stored efficiently and anomalies during insert, update, or delete operations are avoided.

5) What is a stored procedure?
A stored procedure is a precompiled set of SQL statements stored in the database. It can accept parameters, perform logic, and return results. Stored procedures improve performance, enhance security by limiting direct table access, and make database logic easier to maintain and reuse.

6) What is the difference between DELETE, TRUNCATE, and DROP?
DELETE removes specific rows from a table and can be rolled back if used inside a transaction. TRUNCATE removes all rows from a table quickly and cannot be rolled back, but it keeps the table structure. DROP removes the entire table, including its structure and data.

7) What is a transaction in SQL Server?
A transaction is a group of SQL operations that are executed as a single unit of work. It follows the ACID properties: Atomicity, Consistency, Isolation, and Durability. Transactions ensure that either all operations succeed or none are applied, protecting data from corruption.

8) What is a view?
A view is a virtual table created by a SQL query. It does not store data itself but provides a way to simplify complex queries, improve security, and present data in a specific format. Views are often used to limit user access to certain columns or rows.

9) What is indexing and why is it important?
Indexing improves query performance by allowing SQL Server to find data faster instead of scanning the entire table. Proper indexing significantly reduces query execution time, especially for large tables. However, too many indexes can slow down insert and update operations, so they must be used carefully.

10) What is a deadlock in SQL Server?
A deadlock occurs when two or more transactions block each other by holding locks on resources that the other needs. SQL Server detects deadlocks automatically and terminates one of the transactions so the others can continue. Proper indexing, consistent locking order, and short transactions help reduce deadlocks.
