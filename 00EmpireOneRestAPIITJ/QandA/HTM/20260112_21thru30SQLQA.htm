21) What is a schema in SQL Server?
A schema is a logical container that groups database objects such as tables, views, and stored procedures. It helps organize objects, avoid name conflicts, and control security. For example, two tables can have the same name if they are in different schemas.

22) What is the difference between a heap and a clustered table?
A heap is a table without a clustered index, meaning data is stored in no particular order. A clustered table has a clustered index, which defines the physical order of the data. Queries that use range searches or sorted data generally perform better on clustered tables.

23) What is a SQL Server index fragmentation?
Fragmentation occurs when the logical order of index pages does not match the physical order on disk. This can slow down query performance. SQL Server provides index reorganize and rebuild operations to reduce fragmentation and improve performance.

24) What is a parameterized query?
A parameterized query uses parameters instead of hard-coded values in SQL statements. This improves performance by allowing query plan reuse and also helps protect against SQL injection attacks.

25) What is the difference between UNION and UNION ALL?
UNION combines the results of two queries and removes duplicate rows. UNION ALL combines results but keeps all rows, including duplicates. UNION ALL is faster because it does not perform duplicate elimination.

26) What is a surrogate key?
A surrogate key is an artificial primary key, usually an identity column or GUID, that has no business meaning. It is used to uniquely identify rows when natural keys are too large or complex.

27) What is the difference between CHAR and VARCHAR?
CHAR is a fixed-length data type and always uses the same amount of storage. VARCHAR is variable-length and uses only as much space as needed. VARCHAR is more space-efficient when storing data of varying lengths.

28) What is the purpose of the MERGE statement?
The MERGE statement allows you to insert, update, or delete rows in a target table based on a comparison with a source table. It is commonly used for synchronization and data loading operations.

29) What is tempdb and why is it important?
tempdb is a system database used to store temporary objects, intermediate query results, and versioned rows. Many SQL Server operations rely on tempdb, so its performance and configuration have a major impact on overall database performance.

30) What is a correlated subquery?
A correlated subquery is a subquery that depends on values from the outer query. It runs once for each row processed by the outer query. While powerful, correlated subqueries can be slow and should be used carefully in large datasets.
