What is Lazy vs Eager loading in c#?

In C#, lazy loading and eager loading are two strategies used primarily with Entity Framework (EF / EF Core) to control how related data is retrieved from the database. Lazy loading means related entities are not loaded from the database until they are explicitly accessed in code; when a navigation property is first referenced, EF automatically issues an additional database query to load that data. This approach can reduce initial query cost but may lead to performance problems such as the “N+1 query” issue if many related entities are accessed in a loop. Eager loading, on the other hand, loads related data as part of the initial query using methods like Include() and ThenInclude(), resulting in a single (or fewer) database queries that fetch all required data upfront. While eager loading can retrieve more data than needed if overused, it provides more predictable performance and is generally preferred in scenarios where related data is known to be required.

Summary

Lazy loading defers loading related data until it is accessed, while eager loading loads related data immediately with the main query; eager loading is often favored for performance predictability and avoiding excessive database calls.
