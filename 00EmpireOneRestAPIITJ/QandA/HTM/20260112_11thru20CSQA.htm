11) What is boxing and unboxing in C#?
Boxing is the process of converting a value type, such as an int, into a reference type like object. Unboxing is the reverse process, where the value is extracted back into a value type. Boxing and unboxing have performance costs because they involve memory allocation and type conversion, so they should be avoided in performance-critical code whenever possible.

12) What is the difference between var and dynamic?
var is strongly typed and the compiler determines the type at compile time, meaning the variable’s type cannot change. dynamic, on the other hand, is resolved at runtime and bypasses compile-time type checking. While dynamic provides flexibility, it can lead to runtime errors if misused, so var is generally preferred for safety and performance.

13) What are extension methods?
Extension methods allow you to add new methods to existing types without modifying their source code or creating a new derived type. They are defined in static classes and are called like instance methods. Extension methods are widely used in LINQ and make code more readable and expressive.

14) What is a nullable type in C#?
A nullable type allows value types, such as int or DateTime, to store null. This is done using the ? syntax, for example int?. Nullable types are useful when working with databases or situations where a value may be missing or undefined.

15) What is the purpose of the using statement?
The using statement ensures that unmanaged resources such as file handles, database connections, and streams are properly released when they are no longer needed. It automatically calls the Dispose method at the end of the block, even if an exception occurs, making resource management safer and cleaner.

16) What is a singleton design pattern?
The singleton pattern ensures that only one instance of a class exists in an application and provides a global access point to it. It is commonly used for logging, configuration, and caching. In C#, this is typically implemented using a private constructor and a static instance property.

17) What is the difference between readonly and const?
const fields are compile-time constants and must be assigned a value when declared. readonly fields are assigned at runtime, usually in a constructor, and cannot be changed afterward. readonly is more flexible and is often used when values depend on runtime data.

18) What is reflection in C#?
Reflection allows a program to inspect its own metadata, such as types, methods, properties, and attributes, at runtime. It is often used in frameworks, dependency injection, and serialization. While powerful, reflection can be slower than normal code execution and should be used carefully.

19) What is the difference between throw and throw ex?
Using throw preserves the original stack trace of an exception, making debugging easier. Using throw ex resets the stack trace and hides where the exception originally occurred. Best practice is to use throw when rethrowing an exception.

20) What are attributes in C#?
Attributes are metadata that can be applied to classes, methods, properties, and other program elements. They provide additional information that can be read at runtime using reflection. Attributes are commonly used for validation, serialization, and framework configuration.
