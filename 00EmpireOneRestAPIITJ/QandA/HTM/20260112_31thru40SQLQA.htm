31) What is a SQL Server deadlock and how do you resolve it?
A deadlock occurs when two or more transactions block each other by holding locks on resources that the other needs. SQL Server automatically detects this and terminates one of the transactions so the others can continue. Deadlocks can be reduced by keeping transactions short, accessing tables in the same order, and using proper indexing.

32) What is the difference between NOT IN and NOT EXISTS?
NOT IN returns no rows if the subquery contains a NULL value, which can lead to unexpected results. NOT EXISTS checks for the existence of matching rows and works correctly even when NULLs are present. For this reason, NOT EXISTS is generally safer and more reliable.

33) What is SQL Server isolation level?
Isolation levels control how transactions interact with each other and how data is locked. Common levels include Read Uncommitted, Read Committed, Repeatable Read, Serializable, and Snapshot. Higher isolation levels provide more consistency but reduce concurrency.

34) What is snapshot isolation?
Snapshot isolation uses row versioning instead of locking to provide a consistent view of the data. Each transaction sees the data as it existed when the transaction started. This improves concurrency and avoids blocking, but it requires additional storage in tempdb.

35) What is a SQL Server cursor?
A cursor allows you to process rows one at a time rather than as a set. While cursors are sometimes necessary, they are generally slower and less efficient than set-based operations and should be avoided when possible.

36) What is a covering index and why is it useful?
A covering index includes all the columns needed to satisfy a query, allowing SQL Server to retrieve results without accessing the table itself. This significantly improves query performance by reducing disk I/O.

37) What is a fill factor in SQL Server?
Fill factor determines how much space is left on each index page when an index is created or rebuilt. Leaving free space helps reduce page splits when new data is inserted, improving performance in heavily updated tables.

38) What is the difference between GETDATE() and SYSDATETIME()?
GETDATE() returns the current date and time with lower precision, while SYSDATETIME() returns a more precise date and time including fractional seconds. SYSDATETIME() is preferred when higher precision is needed.

39) What is a SQL Server Agent?
SQL Server Agent is a service that allows you to automate tasks such as backups, index maintenance, and data imports by scheduling jobs. It is essential for maintaining and managing production databases.

40) What is the difference between a view and a materialized view?
A regular view is a stored query that runs each time it is accessed, while a materialized view, called an indexed view in SQL Server, stores the result set physically on disk. Indexed views improve performance for complex queries but require additional maintenance overhead.
