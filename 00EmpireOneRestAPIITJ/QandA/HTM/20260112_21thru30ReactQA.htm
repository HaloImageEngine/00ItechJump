21) What is the difference between useRef and createRef in React?
Both useRef and createRef are used to access DOM elements or persist values across renders, but they differ in behavior. createRef creates a new ref each time a component renders, making it suitable for class components. useRef returns the same ref object across renders, making it ideal for functional components to maintain persistent values without causing re-renders.

22) What is the difference between React Router and traditional routing?
React Router is a library for handling routing in single-page applications (SPA) built with React. Unlike traditional routing, which requests a new HTML page from the server for each route, React Router dynamically renders components on the client side without refreshing the page, resulting in faster navigation and a smoother user experience.

23) What is the difference between componentDidMount and useEffect?
componentDidMount is a lifecycle method in class components that runs once after the component is mounted. useEffect in functional components can replicate this behavior by passing an empty dependency array, running the effect only once after the component mounts. useEffect is more versatile because it can also respond to dependency changes.

24) What is prop drilling and how can it be avoided?
Prop drilling occurs when data is passed through multiple intermediate components just to reach a deeply nested component. It can lead to harder-to-maintain code. Prop drilling can be avoided using React Context, Redux, or other state management libraries to provide global access to the required data.

25) What is the difference between React.StrictMode and ErrorBoundary?
React.StrictMode is a development tool that highlights potential issues and runs certain methods twice to detect side effects, but it does not handle errors. ErrorBoundary is a component that catches JavaScript errors in its child component tree and renders a fallback UI, preventing the whole application from crashing.

26) What are controlled forms versus uncontrolled forms in React?
Controlled forms have their input values tied to React state, with changes handled via event handlers. This allows validation and dynamic updates. Uncontrolled forms manage their own state internally, and values are accessed via refs. Controlled forms provide more predictable behavior and are recommended in most cases.

27) What is code splitting in React?
Code splitting is a technique to split the application bundle into smaller chunks that are loaded on demand. React supports this using React.lazy and dynamic imports. Code splitting improves performance by reducing the initial load time of large applications.

28) What is the difference between useImperativeHandle and forwardRef?
forwardRef allows a parent component to pass a ref to a child component, giving access to its DOM or instance. useImperativeHandle is used inside the child component to customize which values or methods are exposed to the parent through the ref. Together, they provide controlled access to child functionality.

29) What is the difference between state lifting and React Context?
State lifting involves moving shared state up to a common parent to allow multiple child components to access it via props. React Context provides a way to share data globally without passing props through every intermediate component. Context is preferable when many components across the tree need access to the same data.

30) What is the difference between client-side rendering and static site generation in React?
Client-side rendering (CSR) renders content in the browser using JavaScript after the HTML is loaded, which may cause slower initial load times. Static site generation (SSG) pre-renders pages at build time into HTML, improving performance and SEO. Frameworks like Next.js enable both CSR and SSG approaches.
