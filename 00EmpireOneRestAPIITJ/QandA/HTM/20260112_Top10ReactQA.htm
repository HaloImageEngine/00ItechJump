1) What is React and why is it used?
React is a JavaScript library developed by Facebook for building user interfaces, particularly single-page applications. It allows developers to create reusable UI components, manage the state of applications efficiently, and update the DOM efficiently using a virtual DOM. React’s component-based architecture makes it easier to maintain and scale large applications.

2) What is the difference between a class component and a functional component in React?
Class components are ES6 classes that extend React.Component and can have state and lifecycle methods. Functional components are plain JavaScript functions that can return JSX and, with the introduction of hooks, can now also manage state and use lifecycle features. Functional components are simpler and preferred in modern React development.

3) What are React Hooks?
Hooks are special functions introduced in React 16.8 that allow functional components to use state and other React features like lifecycle methods. Common hooks include useState, useEffect, useContext, useRef, and useReducer. Hooks make it easier to share logic between components and reduce the need for class components.

4) What is the virtual DOM and how does it work in React?
The virtual DOM is an in-memory representation of the real DOM. When the state of a component changes, React updates the virtual DOM first, compares it with the previous version (diffing), and then efficiently updates only the parts of the real DOM that have changed. This improves performance and reduces unnecessary re-renders.

5) What is the difference between controlled and uncontrolled components?
Controlled components have their form data managed by React state, meaning the value of the input is driven by state and changes are handled via event handlers. Uncontrolled components store their own state internally, and React accesses the value using refs. Controlled components provide better control and validation of user input.

6) What is the purpose of useEffect in React?
The useEffect hook allows you to perform side effects in functional components, such as fetching data, updating the DOM, or subscribing to events. It can be configured to run after every render, only on specific dependencies, or once on component mount, making it a flexible replacement for lifecycle methods like componentDidMount and componentDidUpdate.

7) What is React Context and when should you use it?
React Context is a way to share state or data across multiple components without passing props down manually at every level. It is useful for global data such as themes, user authentication, or language preferences. Context should be used sparingly to avoid unnecessary re-renders and complexity.

8) What is the difference between React.memo and useMemo?
React.memo is a higher-order component used to memoize functional components, preventing unnecessary re-renders when props do not change. useMemo is a hook that memoizes the result of a calculation or function, recomputing it only when dependencies change. Both help improve performance but are used in different contexts.

9) What is the difference between state and props in React?
Props are read-only values passed from parent to child components, allowing data to flow down the component tree. State is managed within a component and can change over time, triggering re-renders. Props make components reusable, while state makes components interactive and dynamic.

10) What is the difference between useState and useReducer?
useState is a hook for managing simple state variables in functional components. useReducer is used for more complex state logic involving multiple related values or actions, following a reducer pattern similar to Redux. useReducer provides a predictable way to handle state updates in complex components.
