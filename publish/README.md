## Notes

- **Prod UI** calls **`https://api.itechjump.com`** directly (`useSameOriginApi: false`). UI `web.config` is SPA-only (no `/api` reverse proxy). API site: `publish/api` on `api.itechjump.com` with HTTPS.
- Host the UI and API on URLs that match production CORS and API origin settings, or adjust `environment.prod.ts` / API CORS before publishing.
- `build-info.txt` records the last publish timestamp and `versionId` (`C` + `YYMMDD`, e.g. `C261122`).
- API splash `index.html` reads **`VersionId`** from `Web.config` via `GET /api/status/version`.
